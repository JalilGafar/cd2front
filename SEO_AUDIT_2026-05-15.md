## 5. SYNTHÈSE — 5 PROBLÈMES PRIORITAIRES CLASSÉS PAR IMPACT

### 🔴 **Problème #1 : Pages dynamiques sans Title/Meta (InfoDomaine, InfoFormation, InfoMetier)**
**Impact estimé** : 🔴 TRÈS ÉLEVÉ (170+ pages)

**Diagnostic** : Les composants `InfoDomaineItemComponent`, `InfoFormationItemComponent`, et `InfoMetierItemComponent` n'injectent pas le service `Title` ou `Meta`. Ces pages sont dans `routes.txt` (prérendues) mais le SSR servira un `<title>Cdfront</title>` générique.

**Recommandation** : Implémenter `initMetaForMyPage()` dans ces 3 composants (pattern identique à `InfoEcoleItemComponent` et `SingleActuComponent`). Injecter `Title` + `Meta` dans le constructeur, appeler `initMeta()` après le `tap()` de fetch API.

---

### 🔴 **Problème #2 : Absence de balises Open Graph et JSON-LD**
**Impact estimé** : 🔴 TRÈS ÉLEVÉ (social signals + rich results)

**Diagnostic** : Zéro balise `og:*` et zéro schéma JSON-LD. Les partages sur les réseaux sociaux et les rich snippets Google ne sont pas optimisés.

**Recommandation** : Créer un service `SeoService` qui ajoute les balises OpenGraph (`og:title`, `og:description`, `og:image`, `og:url`) et un schéma JSON-LD basique (Organization + Article). Appeler ce service pour chaque page dynamique après le fetch des données.

---

### 🟠 **Problème #3 : Gap routes.txt vs BDD (24 écoles, 44 domaines non prérendues)**
**Impact estimé** : 🟠 MOYEN-ÉLEVÉ (170+ pages en CSR)

**Diagnostic** : Le fichier `routes.txt` contient 184 écoles mais AboutComponent affiche 208 (gap de 24). Même gap pour les domaines (120 vs 164 = 44 manquants). Ces pages seront rendues en CSR, impactant le crawlability.

**Recommandation** : Automatiser la génération de `routes.txt` depuis la BDD à la build. Script Node qui :
1. Appelle `GET /api/ecoles`, `GET /api/domaine`, `GET /api/actualite`
2. Génère les slugs et routes
3. Écrit dans `routes.txt`
Cela garantit que chaque nouvelle entrée en BDD est automatiquement prérendues.

---

### 🟠 **Problème #4 : Pages statiques sans Title/Meta (about, faq, legal, etc.)**
**Impact estimé** : 🟠 MOYEN (5 pages)

**Diagnostic** : Les pages `/about`, `/faq`, `/legal`, `/politique`, `/condition` ne définissent pas de Title ni de description. L'utilisateur verra un titre par défaut générique.

**Recommandation** : Injecter `Title` + `Meta` dans chaque composant et appeler `setTitle()` + `updateTag()` dans le constructeur. Valeurs statiques acceptables puisque ces pages sont statiques.

---

### 🟡 **Problème #5 : robots.txt pointe mal + sitemap.xml généré manuellement**
**Impact estimé** : 🟡 FAIBLE-MOYEN (indexation + maintenance)

**Diagnostic** : `robots.txt` pointe vers `Sitemap: https://www.camerdiplome.com` (domaine racine) au lieu du fichier `sitemap.xml`. Le sitemap.xml est généré manuellement par Screaming Frog (dépendance externe).

**Recommandation** : 
1. Corriger `robots.txt` : `Sitemap: https://www.camerdiplome.com/sitemap.xml`
2. Génération automatique du `sitemap.xml` au build via la lib `sitemap` (déjà dans package.json) ou `@nguniversal/express-engine`
