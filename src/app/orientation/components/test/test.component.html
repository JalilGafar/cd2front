Qu'est-ce que le test RIASEC ?

Le test RIASEC, également appelé test de Holland, est un outil d'orientation professionnelle développé par le psychologue américain John L. Holland dans les années 1950. C'est l'un des modèles les plus utilisés au monde pour identifier les intérêts professionnels et trouver les métiers adaptés à chaque personnalité.

Le modèle repose sur l'idée que les individus et les environnements de travail peuvent être classés selon 6 types de personnalité, dont l'acronyme forme le mot RIASEC. Chaque personne présente une combinaison unique de ces 6 dimensions, avec généralement 2 à 3 types dominants.

Comment fonctionne notre test RIASEC gratuit ?

Notre test RIASEC comprend 60 affirmations (10 par dimension). Pour chaque affirmation, vous indiquez votre degré d'accord sur une échelle de 1 à 5. Il n'y a pas de bonnes ou mauvaises réponses : choisissez ce qui vous correspond le mieux spontanément.

À la fin du test, vous obtenez votre profil RIASEC personnalisé avec un graphique radar, une description de vos types dominants, et une sélection de métiers compatibles parmi nos fiches métiers.
